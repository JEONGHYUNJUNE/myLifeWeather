# 내 인생 날씨

생년월일과 기간별 생활지역을 바탕으로 Open-Meteo 과거 날씨를 분석하는 한국어 모바일 우선 웹앱입니다. 로그인과 데이터베이스 없이 동작합니다.

## 실행

```bash
pnpm install
pnpm dev
```

검증은 `pnpm test`, `pnpm typecheck`, 프로덕션 빌드는 `pnpm build`로 실행합니다. 별도 API 키는 필요하지 않습니다. `NEXT_PUBLIC_ANALYTICS_ENABLED=true`일 때만 비식별 이벤트 인터페이스가 콘솔 기반으로 활성화됩니다.

## 데이터와 개인정보

- 도시 검색: Open-Meteo Geocoding API
- 날씨: Open-Meteo Historical Weather API (`archive-api.open-meteo.com`)
- 생년월일과 생활 이력은 서버 DB에 저장하지 않고 작성 중 초안만 브라우저 `localStorage`에 둡니다.
- API Route Handler가 좌표·기간을 검증하고 장기 캐시를 적용합니다.
- 공유 이미지에는 생년월일, 좌표, 상세 생활기간이 포함되지 않습니다.

학교·직장 활동지역을 입력하면 지정 요일에는 활동지역, 나머지 날에는 거주지역의 하루 기록 하나만 선택합니다. 이는 실제 이동기록이 아닌 생활패턴 기반 추정이며 공휴일·휴가·방학·재택근무는 반영하지 않습니다.

## 통계 기준과 한계

눈(0.1cm), 비(0.1mm), 일조율/운량 순으로 날짜당 대표 날씨 하나를 정합니다. 폭염성 날(최고 33℃ 이상), 열대야성 날(최저 25℃ 이상), 강추위 날(최저 -12℃ 이하), 폭우 날(80mm 이상)은 서비스 자체 기준이며 공식 특보 이력이 아닙니다. 자료는 도시 좌표 기준 재분석 값으로 실제 특정 주소의 순간 날씨와 다를 수 있습니다. 2월 29일생의 생일은 윤년에만 집계합니다.
